Data Deletion

Arena Shooter stores game progress locally on your device. Ads are served through Google AdMob, which stores its own data separately. There are no accounts or cloud saves.

✅ No Email Required for Game Data 📢 AdMob Data Managed by Google 📱 Local Game Data Only

🚀 Quickest method: Just uninstall the app. All game data is deleted automatically. For ad data, visit Google's Ad Settings.

What data exists

Game data (local):

  • Level progress, stars earned, high scores
  • Coins, diamonds, XP, player level
  • Purchased unlocks (skins, bullets, shields, backgrounds, trails)
  • Settings (difficulty, audio, screen shake)
  • Stats (kills, boss kills, games played)
  • Endless mode best wave and score

Ad data (managed by Google AdMob):

  • Advertising ID
  • Ad interaction data (impressions, clicks)
  • Device data used for ad personalization

Delete game data

📱 Method 1: Uninstall (Recommended)

  1. Long-press the Arena Shooter icon on your home screen
  2. Tap Uninstall
  3. Confirm
  4. ✅ All local game data is permanently deleted

🗑️ Method 2: Clear App Data (keep app installed)

  1. Open Settings on your Android device
  2. Go to Apps → Arena Shooter
  3. Tap Storage
  4. Tap Clear Data
  5. Confirm
  6. ✅ All progress reset to zero, as if first install

Delete AdMob ad data

📢 Ad data is collected and managed by Google, not by Rockshell Studios. To delete or manage your ad data:

  • Visit https://adssettings.google.com
  • Go to Android Settings → Google → Ads → Delete advertising ID
  • Reset your Advertising ID to remove previous ad associations
  • Opt out of ad personalization to prevent future tracking

What happens after deletion

  • All level progress lost — start from Level 1
  • All coins, diamonds, and XP reset to zero
  • All purchased unlocks gone (skins, bullets, etc.)
  • Player level returns to 1
  • Endless mode high scores erased
  • Settings return to defaults

This action cannot be undone.
