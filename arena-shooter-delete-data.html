Data Deletion

Arena Shooter stores all data locally on your device. There are no accounts, no servers, and no cloud saves — so deleting your data is simple and instant.

✅ No Email Required 📱 Local Data Only ⚡ Instant Deletion

🚀 Quickest method: Just uninstall the app. All data is deleted automatically.

What data exists

  • Game progress: completed levels, stars earned
  • Currency: coins, diamonds, XP, player level
  • Unlocks: skins, bullets, shields, backgrounds, trails
  • Settings: difficulty, audio, screen shake
  • Stats: total kills, boss kills, games played
  • Best scores: endless mode wave and score records

Method 1: Uninstall (Recommended)

📱 Uninstall the app

  1. Long-press the Arena Shooter icon on your home screen
  2. Tap Uninstall
  3. Confirm
  4. ✅ All data is permanently deleted

Method 2: Clear App Data

🗑️ Clear data without uninstalling

  1. Open Settings on your Android device
  2. Go to Apps → Arena Shooter
  3. Tap Storage
  4. Tap Clear Data
  5. Confirm
  6. ✅ All progress reset to zero, as if first install

Method 3: Clear Cache

Note: Clearing cache only removes temporary files, not your save data. Use Clear Data (Method 2) to reset progress.

What happens after deletion

  • All level progress is lost — you start from Level 1
  • All coins, diamonds, and XP are reset to zero
  • All purchased unlocks are gone (skins, bullets, etc.)
  • Player level returns to 1
  • Endless mode high scores are erased
  • Settings return to defaults

This action cannot be undone.

No server-side data

Arena Shooter does not store any data on external servers. There is no "account" to delete, no database to wipe, and no email request needed. Once you clear local data or uninstall, it's gone for good.
